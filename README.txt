LUMIÈRE BEAUTY — DEMO SITE

Файлы:
- index.html — структура сайта
- styles.css — дизайн и адаптивная вёрстка
- script.js — меню, модальные окна, галерея и демонстрационная форма

Как открыть:
1. Распакуйте архив.
2. Откройте папку в VS Code.
3. Запустите index.html через расширение Live Server или просто откройте файл в браузере.

Важно:
- Это демонстрационный проект.
- Форма не отправляет и не сохраняет данные.
- Изображения и шрифты загружаются из интернета, поэтому для них нужен интернет.
- Услуги, цены, расписание и адрес демонстрационные — замените на реальные перед запуском для клиента.
